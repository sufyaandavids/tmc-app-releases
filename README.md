# The Money Chronicle for Windows

Free trading journal for Windows 10/11. A macOS app is not available.

[Download the latest Windows installer](https://github.com/sufyaandavids/tmc-app-releases/releases/latest) · [Windows setup and updates](https://themoneychronicle.pages.dev/guide#updates) · [Website](https://themoneychronicle.pages.dev/)

Install over your current Windows app or use Settings → App updates. Your journal and settings stay in the same data folder. Do not uninstall or clear app data to update. In-app updates verify the TMC publisher signature and installer, and create an encrypted local backup before installation. The installer does not have a Windows-trusted Authenticode certificate.

This repository contains Windows releases. Source code is maintained in a private repository.

[TMC Mobile for iPhone and Android](https://the-money-chronicle.sufyaan-davids786.workers.dev) has a [separate release channel](https://github.com/sufyaandavids/tmc-mobile-releases). Phone and Windows journals remain on each device and do not automatically sync.
